# Labyrinth of Shadows

An interactive maze exploration game with flashlight mechanics and strategic gameplay.

## Game Overview

Navigate through a shadowy labyrinth using limited flashlight time to memorize the maze, then guide your character to safety while avoiding dead ends.

## How to Play

1. **Start Screen**: Click "Start Exploration" to begin your journey
2. **Flashlight Phase**:
   - Move your mouse to reveal parts of the maze with a circular flashlight beam
   - You have 10 seconds to memorize the maze layout
   - The flashlight automatically follows your mouse cursor
   - Use this time wisely to plan your route!

3. **Movement Phase**:
   - After the flashlight time expires, control a character through the maze
   - Move your mouse to guide the character's direction
   - Only a small area around your character is visible
   - Find the safe path to reach the goal (marked with 🏠)

4. **Lives & Flashlights**:
   - You have 3 lives (shown as hearts ♥)
   - You have 3 flashlight uses (shown as 🔦)
   - If you enter a dead end, you lose a life and return to flashlight phase
   - Lose all lives and it's game over!

5. **Winning**: Navigate the correct path to reach the goal and win!

## Game Features

- **Dynamic Maze Generation**: Each playthrough features a unique maze layout
- **Strategic Gameplay**: Only ONE correct path exists - all others lead to dead ends
- **Atmospheric Design**: Black and white aesthetic with ornate Victorian-style borders
- **Desktop Optimized**: Designed specifically for mouse-based interaction

## Running the Game

Simply open `index.html` in a modern web browser (Chrome, Firefox, Safari, or Edge).

No installation or build process required!

## Controls

- **Mouse Movement**: Control flashlight position (flashlight phase) or character direction (movement phase)
- **Click**: Interact with buttons and UI elements
- **Home Icon** (🏠): Return to start screen at any time

## Tips

- During the flashlight phase, try to trace the entire path from start to finish
- Look for paths that lead to the bottom-right corner (goal location)
- Dead ends often look tempting - study the maze carefully!
- The correct path is never obvious at first glance

## Technical Details

- Pure HTML5, CSS3, and vanilla JavaScript
- Canvas-based rendering for smooth graphics
- Responsive design that adapts to window size
- No external dependencies required

Enjoy the challenge of the Labyrinth of Shadows!
